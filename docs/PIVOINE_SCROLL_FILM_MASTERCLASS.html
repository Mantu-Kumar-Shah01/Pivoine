Reverse-Engineering Pivoine & Continuous Scroll-Films

Complete technical blueprint, physics equations, asset preparation, and multi-threaded Web Worker architecture for 60–120 FPS canvas experiences.

1. The Fundamental Architecture

The continuous scroll-film experience bypasses traditional web animation paradigms. The entire narrative is driven by an image sequence rendered on an HTML5 <canvas> that is scrubbed in sync with smooth scroll inertia.

Technology Conventional Method (Fails) Pivoine Engine (Succeeds)
Playback Primitive <video currentTime=...> (35-60ms seek lag, dropped frames) HTML5 <canvas> (2D opaque context) blitting discrete pre-decoded frames.
Image Decoding Main thread new Image() (causes UI stutters & freezes) Web Worker Pool with createImageBitmap zero-copy transfers.
Physics & Scrolling Native OS scroll event listeners (jittery) Lenis smooth scroll coupled with exponential Tau damping.
Memory Management Store all frames in memory (crashes iOS Safari WebKit at ~250MB) Sliding window cache (24–48 frames) with explicit .close() garbage collection.

2. The 4-Tier Progressive Streaming Engine

To support over 1,200 frames without crashing mobile memory or causing network lag, Pivoine implements four distinct memory layers:

Tier 1: Compressed Blobs

Whole reel stored as compressed WebP blobs (50-80MB). Initial 40 frames load first, then steps 64 → 32 → 16 → 1.

Tier 2: Sliding Decoded Window

24 to 48 uncompressed ImageBitmap frames surrounding the current scroll cursor, decoded ahead based on scroll velocity.

Tier 3: Low-Res Fallback Grid

1 of every 8 frames kept resident at low resolution (600px). Used during violent mobile flings to guarantee zero blank frames.

Tier 4: Resting Native Frame

Ultra-sharp unscaled native image decoded precisely when scrolling halts for over 100ms.

3. Asset Creation & AI Frame Interpolation (RIFE 4x)

  1. 3D / AI Camera Movement: Render a continuous 24–30 FPS sequence in Blender, Cinema 4D, or Kling AI.
  2. RIFE 4x Interpolation: Pass the video through RIFE AI to expand 300 frames to 1,200 frames. This reduces pixel displacement between steps to ~2.5px, eliminating discrete visual stepping.
  3. Dual Reel Art Direction:
    • Desktop (16:9): 1928×1072 WebP. Product focal point centered/right (fx: 0.6) to preserve the left third for typography.
    • Mobile (9:16): 720×1280 (scrub) & 1072×1928 (rest). Product lowered to clear space for top-anchored headers.
  4. FFmpeg WebP Batch Command: 
    ffmpeg -i input.mov -vf "fps=60" -vcodec libwebp -quality 82 -lossless 0 frames/f_%04d.webp

4. Multi-Threaded Worker Decoding Engine

The worker decodes image data off the main thread and transfers ownership directly without memory cloning:

// Web Worker Image Decoder (Zero-Copy Transfer)
onmessage = async (e) => {
  const { id, url } = e.data;
  try {
    const res = await fetch(url);
    const blob = await res.blob();
    const bmp = await createImageBitmap(blob);
    postMessage({ id, bmp }, [bmp]); // Transferable memory
  } catch (err) {
    postMessage({ id, err: true });
  }
};

5. Unified Lenis & Canvas Physics Loop

Exponential Tau smoothing prevents frame jumping and synchronizes 60Hz, 120Hz, and 240Hz displays:

// Main Thread Render Loop
const EASE_TAU = 24; // ms inertia time-constant

function renderLoop(time) {
  const dt = time - lastTimestamp;
  lastTimestamp = time;

  const delta = targetFrame - curFrame;
  curFrame = Math.abs(delta) > 0.001
    ? curFrame + delta * (1 - Math.exp(-Math.min(dt, 50) / EASE_TAU))
    : targetFrame;

  scheduleLookaheadDecodes();
  drawCoverFitFrame();

  requestAnimationFrame(renderLoop);
}

6. Production Checklist & Mobile Rules

  • ✔ Opaque Canvas Context: Use ctx = canvas.getContext("2d", { alpha: false }) for max GPU throughput.
  • ✔ Explicit Bitmap Disposal: Always call imageBitmap.close() when evicting frames to avoid WebKit Jetsam crashes.
  • ✔ Stable Viewport: Anchor heights using 100svh and 100lvh to prevent mobile URL bar slide jitter.
  • ✔ APCA Contrast Thresholds: Ensure typography has an APCA lightness contrast rating above 80 against video frames.
